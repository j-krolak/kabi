## 🇰abi -  hint-based file explorer

Kabi is a terminal file manager written in Bash, that uses 2-character "hints" for instant navigation.
- ⚡ Hint-Based Jumping: Type 2 letters to instantly open files or enter folders.
- 🛠 Modal Interface: Toggle between Normal, Filter, Visual, and Search modes.
- 📦 Bulk Actions: Select multiple files to Copy, Move, or Delete at once.
- 📊 Disk Usage Analytics: Toggle recursive folder size calculation with the i key.
- 📑 Sorting: Sort by name, size, or time; includes a reverse toggle r.
- 💾 Data Export: Save current directory metadata to a .csv file

cd kabi
